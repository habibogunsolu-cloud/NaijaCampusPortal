# NaijaCampus All-in-One Portal 🇳🇬🎓

An all-in-one academic and examination prep web portal for Nigerian students preparing for **JAMB UTME**, **WAEC SSCE**, **NECO**, **Post-UTME**, and University Admissions.

---

## 🚀 Live Features
- 📚 **Read Hub**: Literature novel study companion (Life Changer, Sweet Sixteen, etc.) with chapter notes, flashcards, CBT drills, and character profiles.
- ⏱️ **Exam Countdown Timers**: Live countdown to official JAMB UTME, WAEC SSCE, and Post-UTME exam sessions.
- 🎯 **JAMB CBT Simulator**: Official 8-key examination simulator (A, B, C, D, N, P, S, R) with real timer and performance breakdown.
- 🏫 **Cut-Off Mark Directory & Aggregate Calculator**: Comprehensive cut-offs for Federal, State, and Private universities, plus aggregate percentage calculator.
- 💡 **AI Admission Counselor**: Smart admission advice and combination guidance.
- 📱 **Progressive Web App (PWA)**: Works offline and installs directly on Android, iOS, and PC.

---

## 🛠️ Tech Stack
- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **PWA**: vite-plugin-pwa, Service Worker, Web Manifest
- **Backend**: Node.js & Express (API proxy & SSR static server)
- **Deployment**: Pre-configured for Vercel, Netlify, Render, or Railway

---

## ⚡ Deployment to Vercel (1-Click)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** -> **"Project"**.
3. Select this repository: `habibogunsolu-cloud/NaijaCampusPortal`.
4. Leave settings as default (Framework Preset: **Vite**, Root Directory: `./`).
5. Click **"Deploy"**.
6. Your live web app link (e.g., `https://naijacampusportal.vercel.app`) will be ready in under 1 minute!
